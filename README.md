# KeyFinder Admin

A modern React admin dashboard built for managing and visualizing application data through a structured, responsive interface.

## ✨ Features
- Dashboard overview
- Data management screens
- Charts and analytics
- Responsive sidebar/navigation
- Reusable React components
- Redux-based state management
- API integration
- Interactive alerts and feedback

## 🛠️ Tech Stack
- React 19
- Vite
- Tailwind CSS
- Redux Toolkit
- React Router
- Axios
- Recharts
- Lucide React
- SweetAlert2

## 🏗️ Architecture
```text
React UI
 ├── Pages / Routes
 ├── Reusable Components
 ├── Redux Store
 ├── API Services
 └── Data Visualization
```

## 🚀 Getting Started
```bash
npm install
npm run dev
```

Production build:
```bash
npm run build
```

Modern React architecture, state management, dashboard UI, charts, responsive design, and scalable frontend organization.
